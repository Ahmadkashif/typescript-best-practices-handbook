## Ten-second version

- **Do:**
  - Use strict TS 7 with `noUncheckedIndexedAccess` and `exactOptionalPropertyTypes`, and only erasable syntax.
  - ESM, `#src/*` imports with `.ts` extensions, Fastify + Zod schemas on every route.
  - Parse env once, use branded IDs and discriminated unions with `assertNever`.
  - `AppError` → problem+json, pino with request ids, `/health` + `/ready`, graceful shutdown.
  - Vitest, type-aware ESLint, a tsdown bundle, a non-root multi-stage image.
- **Don't:**
  - `enum`, `namespace`, parameter properties, decorators, `any`, `as`-casts, `!`, `@ts-ignore`.
  - Default exports, `paths`/`baseUrl`, `../` imports, `process.env` outside config.
  - Floating promises, `*Sync` calls in request paths, swallowed errors.
  - DI containers, Singleton classes, `npm start` in containers, migrations in CMD.
